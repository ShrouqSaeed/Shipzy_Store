# Shipzy Store

A simple C++ command-line store management system implementing basic OOP principles.

---
# Interface (UI) 📸

[docs/home.png](https://github.com/ShrouqSaeed/Shipzy_Store/blob/master/docs/home.png?raw=true)

---

## Features
- Create Account
- User Login
- Display All Products
- Search Product by Name
- Buy Products
- Cancel Products
- Calculate Total
- Forgot Password

## Getting Started

### Prerequisites
- C++ Compiler (e.g., g++ from MinGW-w64)

### Building
Compile the project using a C++ compiler:
```bash
g++ Project.cpp -o Project
```

### Running
Run the executable:
```bash
./Project
```
